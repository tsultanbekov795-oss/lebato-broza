# Lebato Broza 🔥

Соцсеть в стиле Telegram с общей лентой.

## Запуск

```bash
cd lebato-broza
node server/index.js
```

Открой: **http://localhost:3000**

Сразу входишь как гость. Лента общая — все видят посты друг друга.
Лента обновляется каждые 5 секунд.

## Возможности

- Общая лента (мультипользователь)
- Посты, фото, стикеры
- Лайки, репосты, комментарии
- Истории, сообщения, поиск
- Анимации, тёмная/светлая тема
- Логотип Lebato Broza

Без npm — только Node.js.
